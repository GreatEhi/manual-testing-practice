# Manual Testing Practice Project

## Overview
This repository contains structured documentation for manual testing of a sample Login Page.

The goal of this project is to demonstrate understanding of:
- Test Planning
- Test Scenario Writing
- Test Case Design
- Bug Reporting
- Basic QA Documentation Structure
This project simulates real-world QA workflow including execution and defect tracking.

---

## Project Structure

- docs/Test-Plan.md
- docs/Test-Scenarios.md
- docs/Test-Cases.md
- docs/Bug-Reports.md
- docs/Test-Execution-Summary.md

---

## Testing Scope

The system under test (SUT) is a sample Login Page.

Covered areas:
- Valid login
- Invalid login
- Field validation
- Error handling
- Password masking
