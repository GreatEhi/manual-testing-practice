# Test Scenarios – Login Page

1. Verify login with valid username and valid password.
2. Verify login with valid username and invalid password.
3. Verify login with invalid username and valid password.
4. Verify login with empty username and password fields.
5. Verify system response when only username is entered.
6. Verify system response when only password is entered.
7. Verify error message clarity and accuracy.
8. Verify password field masks input characters.
