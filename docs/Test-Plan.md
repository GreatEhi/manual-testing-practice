# Test Plan

## Project Name
Sample Login Page Testing

## Objective
To verify that the login functionality works correctly under valid and invalid conditions.

## Scope
- Login with valid credentials
- Login with invalid credentials
- Empty input fields
- Password visibility toggle (if available)

## Test Type
Manual Testing

## Environment
- Browser: Chrome
- OS: macOS

## Entry Criteria
Application is accessible via browser.

## Exit Criteria
All critical test cases executed and major bugs documented.
